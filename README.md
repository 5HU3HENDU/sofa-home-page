# School of Adults — homepage concepts

Concept mockups for a new School of Adults homepage. **Not the live site** —
nothing here links to schoolofadults.com, and the live site is untouched.

## What's here

- `index.html` — one preview page with five concept boards, all using the same
  hand-drawn flat SVG objects (no AI-generated imagery):
- `desk.html` — the Whole Desk as its own fullscreen page, smart layout: no
  banner, the page measures the real viewport, works out how many icons fit,
  shows all 14 topics plus as many subtopics as fit, and tapping a topic fans
  its subtopics out around it while everything else shrinks and shifts aside
  — all inside one viewport, no scrolling.
  - **A · The Room** — an illustrated scene: shelf, desk, floor.
  - **B · The Shelf** — a clean grid of object cards for all 14 topics.
  - **C · Hero + Shelf** — one "object of the week" over a quiet grid.
  - **D · The Day Strip** — morning to night, objects when you'd reach for them.
  - **E · The Whole Desk** — the current direction: all 14 topics plus
    their 67 subtopics fitted into one viewport (no scrolling) on a stage
    that scales to the screen; repetitions removed (66 icons + 14 compact
    pills instead of 81 repeated icons); tap a cluster to zoom it crisp.
  - **F · Isometric Room** — the same desk as a little 3D world: iso floor and
    furniture, objects standing on them, highlights floating above the scene.
- Tap any object in the preview and it tells you which topic page it would open.

## Highlight rule (applies to every board)

At most 1–2 objects highlighted at once, always with a reason
(a sticky note, a NEW tag, or a "why this week" line).
